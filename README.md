# prototipos
Lugar de almacenamiento de prototipos de dCaC.

## Cómo publicar un prototipo

1. Poné tu archivo `.html` dentro de la carpeta [`prototipos/`](prototipos/).
2. Hacé `git push` a `main`.
3. Quedará disponible en `https://dcacmartinez.github.io/prototipos/prototipos/nombre-del-archivo.html`.

El [`index.html`](index.html) de la raíz es solo una landing fija: no lista ni linkea los prototipos, así que cada uno se comparte por su link directo con quien corresponda.

(La primera vez hay que habilitar Pages en Settings → Pages → Source: "Deploy from a branch" → `main` / `/ (root)`, en el repo de GitHub.)
